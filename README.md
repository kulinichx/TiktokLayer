# AwemeX for iPad

AwemeX for iPad 是基于 DYYY 思路整理的抖音 iPad 图层与长按面板增强插件。当前版本：**V36 / 10.7-36**。

## 主要功能

### 界面设置

- 全局透明度
- 顶部不透明度
- 右侧按钮不透明度
- 右侧按钮缩放比例
- AX 图标不透明度
- 昵称文案缩放
- 昵称 / 文案不透明度
- 隐藏右上搜索
- 隐藏相关搜索 / 合集
- 显示 AX 悬浮按钮
- 浅色 / 深色设置面板

### 面板设置

- 单指长按视频 / 图片弹出 AwemeX 面板
- 保存视频、保存封面、保存音频
- 保存图片、保存所有图片
- 复制文案、复制视频链接
- 保存成功音效
- 保存失败自动复制链接
- 打开原长按面板

## 操作方式

- **双指长按屏幕**：打开 AwemeX 设置面板。
- **单指长按视频 / 图片**：打开 AwemeX 保存面板。

## 构建

本项目使用 Theos 构建：

```bash
make clean package FINALPACKAGE=1
```

GitHub Actions 会自动构建 deb，并将产物重命名为：

```text
AwemeX-for-iPad_<Version>_<RunNumber>.deb
```
